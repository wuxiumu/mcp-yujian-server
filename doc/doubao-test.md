# 豆包接入 yujian-ai MCP 测试文档

> 前提：服务器已按 `deploy-runbook.md` 部署完成，
> `https://mcp-yujian-server.xyxbot.com/healthz` 返回 JSON。

---

## 一、添加自定义连接器（豆包桌面端）

> 豆包目前**仅桌面客户端**支持自定义连接器（浏览器/移动端不行）。

**方式一：对 AI 说（推荐）**

新建对话，整段复制发给豆包：

```
帮我安装一个研报检索的 MCP，具体的 MCP server 配置信息如下:
{
  "mcpServers": {
    "yujian-ai": {
      "type": "streamable-http",
      "url": "https://mcp-yujian-server.xyxbot.com/mcp",
      "timeout": 60
    }
  }
}
```

AI 会自动完成配置，过程中请求确认就同意。装好的标志：连接器列表出现 `yujian-ai`。

**方式二：手动添加**

1. 豆包桌面端左侧菜单：**技能 · 连接器 · 伙伴**
2. 右上角 **新建** → **新建自定义连接器**
3. 填写：
   - 服务名称：`yujian-ai`
   - 传输类型：**HTTP**
   - 服务器 URL：`https://mcp-yujian-server.xyxbot.com/mcp`
   - 自定义 Headers：**留空**（公开服务，无需鉴权）
4. 保存，确认右侧开关已开启

> 无需 Token、无需授权页——本服务是公开只读的研报检索。

---

## 二、验证连接器生效

新开对话，发：

```
使用 yujian-ai，都支持哪些工具
```

期待返回两个工具的说明：

- `search_post`：检索 yujian.ai 研报（关键词/栏目）
- `get_post_detail`：按 post_id 取完整正文

如果豆包回答「没有找到该连接器/工具」，回到连接器页检查开关是否开启、URL 是否多打了空格或少了 `/mcp`。

## 三、功能测试用例

### 用例 1：关键词搜索

```
用 yujian-ai 搜一下储能板块的研报
```

✅ 期待：返回 3-5 条文章列表，含【ID】、标题、时间、摘要；total 显示总数（当前约 18）。

### 用例 2：栏目浏览

```
用 yujian-ai 看看栏目 7 最近有什么文章
```

✅ 期待：返回该栏目文章列表。

### 用例 3：详情链路（搜索 → 读全文）

```
用 yujian-ai 搜索 PCB 研报，然后读一下第一篇的完整内容
```

✅ 期待：先返回列表，豆包自动再调 `get_post_detail(post_id=...)`，输出完整正文（图片显示为 `[图片: url]`，超长文末尾有「已截断」提示）。

### 用例 4：解读日报（综合场景）

```
用 yujian-ai 搜储能和 PCB 的研报，各挑 2 篇读全文，给我写一份今日板块解读日报：
1. 要闻速览（每篇一句话）
2. 核心逻辑解读（论据、数据、结论）
3. 两个板块的共同信号（比如 AI 算力需求）
4. 风险提示
```

✅ 期待：豆包串联多次工具调用（搜索×2 + 详情×4），产出结构化日报。

### 用例 5：异常与边界

| 输入 | 期待 |
|---|---|
| 「搜一个不存在的词：xyzabc123」 | 友好提示未找到，建议换关键词，**服务不崩** |
| 「读 post_id=999999 的文章」 | 提示未找到该文章 |
| 连续快速发 5 条搜索 | 全部正常（无状态模式天然并发安全） |

## 四、服务端配合观察

测试期间在服务器上：

```bash
pm2 logs yujian-mcp --lines 0
# 或
tail -f /opt/mcp-yujian-server/mcp-debug.log
```

每个豆包请求都会记录一行（IP + 请求体前 200 字），可以确认调用确实到达我们的服务、走的哪个工具。

## 五、常见问题

| 症状 | 原因 | 处理 |
|---|---|---|
| 添加时提示无法连接 | 服务未起 / 域名转发指错 | 服务器 `curl 127.0.0.1:3333/healthz`；对照 deploy-runbook.md 排查节 |
| 连接器装上但回答「没有权限/未授权」 | 误选了需要鉴权的模板 | 删掉重装，Headers 留空 |
| 工具调用长时间无响应 | 正文长 + 网络慢 | 重试；或话术指定「只要列表不要全文」 |
| 回答内容是编的（没有调用工具） | 豆包没走 MCP | 话术里显式带「用 yujian-ai」前缀触发 |
